# assets/

Coloca aquí los **logos oficiales** de TOPING y PYME en alta resolución
(`toping.png`/`toping.svg` y `pyme.png`/`pyme.svg`).

La app usa logos provisionales incrustados. Para reemplazarlos de forma
permanente en cada dispositivo, entra a **Perfil → Logos** y súbelos (se
guardan en IndexedDB y se aplican a la interfaz y al encabezado del informe).

> Respeta las proporciones originales; los logos se escalan por altura
> conservando el ancho para no deformarse.
